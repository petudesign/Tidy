# Tidy family visual direction

This is the shared starting point for the small macOS utilities in this project. The product name is provisional; the leaf mark and visual system are the shared elements.

- **Mark:** the existing green leaf icon in `TidyMacApp/Assets.xcassets/TidyLeaf.imageset`.
- **Canvas:** warm light gray `#F4F2ED`; product surface `#FFFEFA`.
- **Primary action:** muted leaf green `#5D8152`, with darker hover/pressed green `#4F7146`.
- **Type:** native SF system font, clear macOS hierarchy, compact file metadata.
- **Surfaces:** open two-column source/plan layout; white panels with quiet gray borders and restrained shadows.
- **Folders:** calm blue `#4B96D3`; category color appears in file icons, not large fills.
- **Interaction:** preview before moving, explicit action, visible completion state, and Undo.
- **Copy:** English inside the product. Use realistic file counts and sizes from the selected folder.

Future related utilities should reuse the mark, typography, canvas, action color, panel geometry, and motion restraint while choosing icons and category colors that match their task.
